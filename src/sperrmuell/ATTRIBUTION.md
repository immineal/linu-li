# Attribution

The data in `data/` (generated by `npm run data`) is derived from two
openly licensed sources. Both are also credited in the app itself (the
"Datenqualität" / "Quellen" panel and the map's attribution control).

## Collection schedule (dates, streets, house-number ranges, route IDs)

- **Source:** bonnorange AöR — "Abfuhrtermine 2026", via opendata.bonn.de
- **URL:** https://opendata.bonn.de/sites/default/files/ABFUHRTERMINE2026OpenData.csv
- **License:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)

When reusing this data, credit "bonnorange AöR / opendata.bonn.de" and
indicate if changes were made (this project parses, filters to "Sperrmüll",
and re-derives geometry and route polygons from it).

## Street, address and Ortsteil geometry

- **Source:** © OpenStreetMap contributors, fetched via the [Overpass API](https://overpass-api.de/)
- **License:** [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/)
- **Details:** https://www.openstreetmap.org/copyright

The street/zone geometry in `data/segments.geojson`, `data/routes.geojson`
and `data/ortsteile.geojson` is a derived database under ODbL — any
redistribution must remain open under ODbL (or a compatible license) and
credit OpenStreetMap contributors.

## Basemap tiles

The app's basemap uses the standard OpenStreetMap raster tiles
(`tile.openstreetmap.org`) per the
[Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/),
attributed as "© OpenStreetMap contributors" in the map's attribution
control. No API key is required. If self-hosting at scale, switch to a
dedicated tile provider per that policy.
