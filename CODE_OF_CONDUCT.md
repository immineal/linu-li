# Code of conduct

Be decent to people. That covers most of it.

More specifically: assume the person you are replying to is trying to help,
say what you mean without making it personal, and drop it when someone asks
you to. Insults, harassment and going after someone's identity are not
welcome, in issues, pull requests or anywhere else connected to this project.

If someone is making this project unpleasant for you, mail me at
immineal@immineal.com. That includes if the someone is me.

I maintain this on my own, so enforcement is whatever I decide it should be:
usually a word, occasionally a block. There is no committee to appeal to.
